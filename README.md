# Matt Thomsen

Source for my personal site: https://mthomsn.github.io/react-portfolio/

A single page built with Create React App. Content lives in `src/App.js`, styles in `src/index.css`.

## Run locally

    npm ci
    npm start

## Deploy

    npm run deploy    # builds and publishes ./build to the gh-pages branch
